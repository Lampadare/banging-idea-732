# VNS Hackathon Notes

## Key Numbers to Cite

- Bovine cervical vagus: ~4mm diameter, elliptical cross-section
- Contains 12-20 fascicles (we model 12)
- Fascicle diameters: 100-600μm
- Tissue resistivity: 300 Ω·cm = 3.0 Ω·m
- Aα motor fibers: 12-20μm diameter, threshold ~0.3-2 mA
- B autonomic fibers: 1-3μm diameter, threshold ~5-15× Aα
- C unmyelinated: 0.4-1.2μm, highest thresholds
